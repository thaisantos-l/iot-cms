# Pacote institucional

Extraído da referência atual em 17/11/2026. Contém textos fornecidos (inclusive etapas originalmente no JS) e somente suas mídias referenciadas. Hashes verificam a origem. O importador cria rascunhos para revisão, registra chaves estáveis e não sobrescreve edições/limpezas. Não cria artigos ou cases. Links das coleções ficam ocultos enquanto vazias.

Textos legais e números comerciais dependem de revisão editorial antes de publicar. O WordPress instalado usa este pacote e não depende do diretório do front. Imagens/vídeos entram na biblioteca como attachments; ícones e logos de interface pertencem ao tema. Nenhum upload de ambiente foi copiado para o Git.
